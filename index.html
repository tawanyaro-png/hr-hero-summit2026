ลงทะเบียนลุ้นรับบัตร Starbucks! ☕

ต้อนรับผู้เข้าชมงาน HR Hero Summit เพียงกรอกข้อมูลเพื่อรับข่าวสารและสิทธิพิเศษจาก PEAK ลุ้นเป็นผู้โชคดีรับบัตร Starbucks (จำนวน 3 รางวัล)

STARBUCKS
CARD

เพื่อให้เป็นไปตามข้อกำหนดทางกฎหมายที่เกี่ยวข้องกับการคุ้มครองข้อมูลส่วนบุคคล บริษัท พี ยู ยู เอ็น อินเทลลิเจนท์ จำกัด (บริษัท) จึงขอให้ท่านให้ความยินยอมในการเก็บรวบรวม ใช้ และเปิดเผยข้อมูลตามเนื้อหาที่แจ้งแก่ท่านดังต่อไปนี้

ข้อมูลที่ทางบริษัทจะเก็บรวบรวม ใช้ และเปิดเผยเผื่อวัตถุประสงค์ ได้แก่

  1. 1. First Name (ชื่อ)
  2. 2. Last Name (นามสกุล)
  3. 3. Email Address (อีเมล)
  4. 4. Phone No. (หมายเลขโทรศัพท์) หรือ Mobile Phone No.(หมายเลขโทรศัพท์มือถือ)

วัตถุประสงค์ของการให้ความยินยอม

  • เพื่อการเสนอผลิตภัณฑ์ บริการ และสิทธิประโยชน์ที่เหมาะสมแก่ท่าน

ผู้ที่จะเข้าถึงข้อมูลของท่านตามความยินยอมนี้ ได้แก่

  • บริษัท และ พนักงานของบริษัทที่ทำหน้าที่อันเกี่ยวข้องกับการนำเสนอผลิตภัณฑ์และบริการ

กรณีที่ท่านไม่ให้ความยินยอม หรือได้ขอใช้สิทธิ์เพิกถอนความยินยอมในภายหลัง ท่านจะพลาดโอกาสในการได้รับข้อเสนอเกี่ยวกับ ผลิตภัณฑ์ บริการ และสิทธิประโยชน์ที่เหมาะสมกับความต้องการของท่านโดยเฉพาะจากบริษัท

ทั้งนี้การให้ความยินยอมแก่บริษัทในครั้งนี้ จะไม่ส่งผลกระทบ หรือเป็นการแก้ไขความยินยอมใดๆ ที่ท่านให้ไว้แก่บริษัทก่อนหน้า

ความยินยอมนี้ท่านสามารถอ่านข้อกำหนดเพิ่มเติมเกี่ยวกับการคุ้มครองข้อมูลส่วนบุคคลของท่าน หรือการขอใช้สิทธิ์ในฐานะเจ้าของข้อมูลส่วนบุคคลได้ที่ dpo@peakengine.com

การกด "ยินยอม" จะเป็นการยินยอมให้บริษัท นำข้อมูลของท่านตามที่ระบุไว้ในความยินยอมนี้ ไปใช้ตามวัตถุประสงค์ตามที่ได้กำหนดไว้ความยินยอมนี้

ลงทะเบียนเรียบร้อยแล้ว!
